# DSA Path

DSA Path is a learning and progress-tracking platform for data structures and algorithms.

It helps learners follow structured roadmaps, track completed and ongoing work, revisit problems left in between, and identify what to learn next.

## Project Status

🚧 Early development

## Initial Goals

- Provide curated DSA learning roadmaps with useful resource links
- Track DSA topics and problem-solving progress
- Organize learning work as To Do, In Progress, Left in Between, and Done
- Help learners identify unfinished topics and revision priorities
- Integrate a Jira-based development workflow
- Add AI-powered guidance in a later phase

## Development Workflow

This project is built incrementally using Jira, OpenCode, GitHub, and MCP integrations:

```text
Jira ticket → Read requirements → Implement one focused change → Test → Pull request → Review → Merge
```

## Planned Scope

The first version will focus on roadmap discovery and personal DSA progress tracking.

Future versions may include:

- Personalized roadmap suggestions
- Problem logs with notes, approaches, and complexity analysis
- Revision reminders and spaced repetition
- Topic and pattern-level analytics
- AI assistance grounded in the learner’s own progress and notes

## Status Definitions

- **To Do:** Planned work not yet started
- **In Progress:** Work currently being implemented or studied
- **Left in Between:** Work intentionally paused, blocked, or deferred for later
- **Done:** Completed and reviewed work
